# Security Policy

## Responsible Use

This tool is designed for **authorized security testing only**. Only use it against:
- APIs you own
- Deliberately vulnerable labs (VAmPI, crAPI)
- Systems where you have explicit written permission

**Never** point this tool at a real website or someone else's API without authorization.

## Reporting Vulnerabilities

If you find a security issue in authz-probe itself, please open a GitHub issue or contact [your-email].
